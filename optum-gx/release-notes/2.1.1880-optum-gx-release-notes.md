# 2.1.1880 Release notes 2026-10-23

**Version:** 2.1.1880   
**Release date:** 23 October 2026  

## New features

- **Graphical core** New OpenGL-based graphics rendering is used throughout Optum GX. While most things looks as before this feature improves performance and overcomes prior limitations.
- **More drawing tools in 3D.** Beams, pile rows, and nail rows are directly available using the 3D drawing tools.
- **Seismic multiplier loads in Limit Analysis.** A new seismic multiplier load option is available when setting up Limit Analysis.
- **Additional elastic material parameter sets.** Parameter sets D and E provide additional options for defining elastic material properties.
- **Python plugin creation wizard.** Use the new wizard to create a Python plugin from scratch or supplied templates. Wizard also supports attaching existing plugins in separate directories.
- **Show deactivated shapes in stages.** A new visibility option lets you display deactivated shapes in a stage.
- **Hinge materials and stiffness.** Define hinge materials with optional rotational stiffness for plate hinges. Hinge materials are also available through the Python API.
- **Steady and transient infiltration.** Analyse infiltration (and evaporation) under steady-state and transient conditions using the new flow boundary condition feature.
- **Axisymmetric lower-bound elements.** Updated axisymmetric lower-bound elements and support for line elements in axisymmetric lower-bound analysis.

## Improvements

- **Table copy and paste.** Updated spreadsheet-style copy and paste in GX tables.
- **More flexible numeric input.** In settings, enter values directly outside a control's slider range.
- **Mesh transparency.** Updated transparency rendering in the model and results views for more consistent display. Accessible through display settings.
- **More precise colour-bar limits.** The minimum and maximum fields in the color-bar menu now show greater numeric precision to reflect the displayed results.
- **Feature names in reports.** Report tables can now include the feature name to help identify the associated model feature.
- **Clearer analysis warnings.** GX now warns when prescribed displacements are used with an analysis type other than deformation analysis.
- **Snapping improvements.** Improved snapping when creating and editing geometry, particularly in 3D.
- **Stage cloning.** Improved inheritance logic of properties when cloning a stage. 
- **Camera clipping and rendering.** Updated camera clipping in model and results views, including clipping-plane calculations based on deformed geometry. Improved rendering of arrows and other graphical indicators near clipping planes and behind the camera.
- **Screenshot API options.** Expanded the options available through the Python `take_picture` API for capturing model and results views.
- **Custom stiffness scaling.** A custom stiffness scale is now also available for the optimization problem set up for the solver.

## Bug fixes

- **Structural self-weight.** Fixed missing self-weight contributions for structural elements, including flat steel plates in 3D. Structural line elements no longer contribute self-weight when the feature is inactive.
- **Partial factors on loads.** Fixed the application of partial factors to loads, including linear loads.
- **Mohr–Coulomb stiffness input.** Fixed an issue with stiffness parameter set C.
- **Unexpected lines in the view.** Fixed unwanted lines appearing in model and results views when using pile rows.
- **3D plate boundary-condition display.** Fixed the orientation of plate boundary-condition symbols in 3D.
- **Unexpected colour picker.** Editing a numeric input in settings no longer unexpectedly opens the color picker.
- **Tetrahedron stiffness and hardening.** Fixed stiffness and hardening-modulus evaluation for tetrahedron elements and updated hardening integration.
- **Reinforced-concrete shell materials.** Fixed an issue with elastic parameters for reinforced-concrete shell materials.
- **Multiplier analysis result points.** Fixed an issue in the MEP multiplier algorithm when the result point is not located at the multiplier load.
- **Elastoplastic solver scaling.** Fixed a scaling issue when using Clarabel for elastoplastic analysis.
- **Nielsen shell self-weight.** Included dry unit weight in Nielsen shell calculations.
