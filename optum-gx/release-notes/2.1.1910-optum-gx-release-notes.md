# 2.1.1910 2026-11-19

**Version:** 2.1.1910
**Planned release date:** 19 November 2026

## New features

- **Time-dependent loads.** Define how supported loads vary over time in the GX interface or through the Python API.
- **Seepage boundary conditions on supports.** Supports now offer a seepage boundary condition as an alternative to the default No Flow condition. GX warns when a separate No Flow condition is applied to a shape with an existing support.
- **Mechanical loads from hydraulic boundaries.** Fixed Head and Fixed Pressure can now also apply the corresponding mechanical water load on external boundaries. When you open an older project that uses either condition, GX prompts you to review any separate loads that represent the same water load.
- **GeoLab plugin.** GeoLab is now bundled with GX to provide a user interface for assessing laboratory test data and calibrating soil material parameters.

## Improvements

- **Stage feature controls.** Add features to stages from the right-click menu and activate or deactivate them across subsequent stages. Editing a feature or material updates the stages where it is active. Unaffected stages remain untouched and keep their analysis status.
- **SI and US project units.** When a project's saved units differ from the current GX units, you can convert the project or directly reopen GX in the project's unit system.
- **Geometry snapping and selection.** Improved snapping inside 2D shapes and when combining grid snapping with line extensions or perpendiculars in 3D. Added geometry selection priorities in 3D and reduced midpoint and centre-point snap flicker.
- **Solver settings.** Added unit-weight and exponent scaling options for Limit Analysis. Elastic and seepage analyses can use the MKL PARDISO or Eigen sparse solver. Python scripts can also configure more solver options.
- **Analysis setup.** Improved the warning when infiltration reaches the internal pressure limit and made the time-scope controls in Factor of Safety consistent with Limit Analysis i.e. only applicable with MCE material.

## Bug fixes

- **Load arrow placement.** Corrected the drawing offsets for multiple loads on the same geometry. Arrows are now grouped by shape and load direction.
- **Seepage stage setup.** GX preserves the source stage when switching from Initial Stress to Seepage Analysis.
- **Feature graphics.** Interface graphics now refresh when the assigned material changes. Corrected the display of Fixed End Anchor markers and the placement of point load and plate boundary-condition symbols.
- **Model and results views.** GX switches back to the Model view when results are unavailable. Fixed a 3D rotation constraint that could lock a skewed view, and corrected when the coordinate-system gizmo appears.
- **Small-scale geometry.** Corrected scaling in very small models and improved the display of support arrows and point loads at close zoom levels.
