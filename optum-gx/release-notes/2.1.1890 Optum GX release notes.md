# 2.1.1890 2026-10-30

**Version:** 2.1.1890  
**Release date:** 30 October 2026

## New features

- **Elastic general plate and beam materials.** Added an elastic option for general plate and beam materials, with corresponding updates to the Python material API.
- **Non-associated Hoek–Brown materials.** Added implementations of non-associated Hoek–Brown materials for 2D and 3D analysis.

## Improvements

- **Curve-width controls.** Added sliders for maximum curve widths in 2D. Updated minimum and maximum curve-width settings for consistent behaviour in 2D and 3D.
- **Adaptive mesh refinement.** Adaptive remeshing now uses the greater of the previous element count and the requested element count, avoiding a reduction below the previous mesh size.

## Bug fixes

- **3D beam elements.** Fixed the element type used for beams in 3D and corrected stress evaluation for elastic 3D beam elements.
- **3D Mohr–Coulomb tension cut-off.** Fixed an issue with the tension cut-off for non-associated Mohr–Coulomb materials in 3D.
- **Load-deformation analysis.** Fixed a further issue with the multiplier option in load-deformation analysis.
- **Adaptive refinement.** Fixed an issue in the adaptive refinement procedure.
- **Camera fitting with hidden selections.** Fixed an issue with camera fitting when a mesh is both hidden and selected.
- **Cone rendering.** Fixed oversized disc caps appearing on cone-shaped graphics.
- **2D coordinate indicator.** The axis widget now follows the coordinate system in 2D.
- **Consolidation degree.** Absolute value of excess pore pressure is now used for calculating consolidation degree.
