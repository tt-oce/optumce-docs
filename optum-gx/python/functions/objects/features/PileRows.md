# PileRows

Pile-row assigned to an edge (2D) or face (3D).

## Examples

```python
feature = model.get_pilerow(shapes)
feature.material_id
feature.base_location()
```

## Properties

<dl>
<dt>material_id : str</dt>
<dt>base_location : str | None</dt>
<dd>Base location: 'begin', 'end', or None.</dd>
</dl>
