# set_point_moment

Add point moment (kNm).

## Parameters

<dl>
<dt>shapes : Shape | ShapeList</dt>
<dd>Shapes to apply the moment to.</dd>
<dt>m : float</dt>
<dd>Moment magnitude in kNm.</dd>
<dt>csys : Csys</dt>
<dd>Coordinate system; coordinate_system takes precedence when supplied.</dd>
</dl>
