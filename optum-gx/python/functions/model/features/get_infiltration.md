# get_infiltration

Get infiltration boundary conditions on the selected shapes.

## Parameters

<dl>
<dt>shapes : Shape | ShapeList</dt>
<dd>Boundary shapes to query.</dd>
</dl>

## Returns

<dl>
<dt>Infiltrations | None</dt>
<dd>Matching infiltration features, or None when no features are found.</dd>
</dl>
